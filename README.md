# 🎪 Балаган

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/alexandrvmr-sudo/balagan)

Вечеринка в духе Jackbox, только по-русски: **телевизор — экран, телефоны — геймпады, ведущий не нужен**. Шесть игр, у каждой свой мир, своя музыка и свой ведущий, который говорит вслух.

## Игры

| Игра | В духе | Игроков | Суть |
|---|---|---|---|
| **Шутка на двоих** | Смехлыст | 3–10 | Ведущая Жанна, дуэли пузырями: двоим одна затравка, зал выбирает, кто смешнее. Финал «Тройной удар» — голосуем медалями. Уровни «Обычный», «18+», «Жесть» |
| **Палата №6** | Смертельная вечеринка | 2–8 | Вязаные пациенты и главврач в советской больнице. Ошибся — на процедуру: таблетки, лифт, рентген, капельница. Умер — играешь призраком. Финал — побег из больницы |
| **Собеседование** | За работой | 3–10 | HR-нейросеть Анжела в ретро-мониторе задаёт вопросы, а отвечать можно только чужими словами, как магнитиками на холодильнике. Мультвставки между раундами, офисные персонажи, режим 18+ |
| **Лайнер** | Стендап-круиз | 3–8 | Стендап на рейсе БГ-404: регистрация, взлёт, набор высоты шутками, выступление в проходе салона — сам жмёшь «Добить!». Турбулентность, кислородные маски и посадка под аплодисменты |
| **Барабан** | Колесо невероятных масштабов | 2–8 | Отвечай — получай сектора, ставь их на Великий Барабан и крути его свайпом. «Банкрот», «Приз», «×2», победитель каждого раунда, Колесо победы. Победитель получает ответ на свой вопрос |
| **Медная гора** | Подземнения | 3–12 | Две команды в шахте Хозяйки угадывают, что думает большинство. За каменной дверью — самоцвет или чудище, которое гасит факел. Вагонетка везёт всё глубже, герои — из сказов Бажова |

Контент написан под российскую компанию 2026 года: маркетплейсы, дача, созвоны, ипотека, мемы года. Что и почему — в [docs/RESEARCH.md](docs/RESEARCH.md).

## Запуск

Двойной клик по **`start.command`** — поставятся зависимости (только в первый раз), поднимется сервер, экран откроется сам, компьютер не уснёт до конца вечеринки.

Из терминала то же самое:

```bash
npm install && npm run party
```

1. Экран (`http://localhost:7700/`) выводим на телевизор. Клик по экрану — включить звук, `F` — полный экран, `M` — переключить звук.
2. Гости сканируют QR с экрана или из терминала. Первый вошедший получает ★ и выбирает игру на телефоне.
3. Все в одной Wi-Fi. Если телефон не открывает адрес — macOS спросит про входящие подключения для `node`, нужно разрешить. В гостевых сетях с изоляцией клиентов раздайте интернет с телефона.

Ведущие говорят нейросетевыми голосами Silero, у каждого свой: Жанна, главврач, Анжела, командир, Великий Барабан, Хозяйка. Поверх голоса `ffmpeg` добавляет характер: у главврача эхо больничного коридора, командир звучит из громкоговорителя, Барабан гулкий. Поставить голос на новом Маке — одна команда (скачает около 150 МБ, на диске займёт около 900 МБ):

```bash
npm run voice
```

Без нейросети говорит голос Мака (Milena) с теми же эффектами, без `ffmpeg` — голос браузера. Субтитры внизу экрана идут всегда. Модели Silero распространяются по лицензии CC BY-NC 4.0: для домашних вечеринок можно, для платных мероприятий — нет.

У хоста в лобби игры переключатель уровня: **Обычный**, **18+** (пошло, но без мата) и **Жесть** (чёрный юмор). В меню — семейный фильтр, который оставляет только обычный контент.

## Проверить одному

```bash
npm run test-party
```

Песочница на `http://localhost:7700/test`: экран и три телефона в одном окне. Первый телефон — хост, у него кнопка **«+ бот»**: боты сами пишут, голосуют, ставят сектора и бегут из санатория. Таймеры укорочены, сервер перезапускается при правке файлов.

Дымовой прогон всех игр без браузера — все шесть, на разном числе игроков, с отвалившимся телефоном и на каждом уровне контента, время ускорено в 50 раз:

```bash
npm run smoke
```

Одна игра: `node scripts/smoke.mjs baraban`. В песочнице есть автопилот для экрана: в консоли `await import('/drive.js'); DRIVE({ game: 'lainer', bots: 4, rating: 'adult' })`, а `HACT({ a: 'skip' })` проматывает таймер.

## ИИ

С ключом Anthropic в `.env` игры становятся персональными:
- **Шутка на двоих** — хост вписывает тему вечера, и затравки пишутся под компанию; ведущая комментирует каждую дуэль.
- **Барабан** — ответ победителю — пророчество именно на его вопрос.

```bash
cp .env.example .env
```

Ключ берётся на [platform.claude.com](https://platform.claude.com) → Settings → API keys, счёт пополняется отдельно от подписки. Без ключа или без денег на счёте всё играется на встроенных паках, а на экране честно написано почему. Запросы идут с резервной моделью на случай отказа основной.

## Свой контент

Всё лежит в `data/` — по файлу на игру. Правите JSON, перезапускаете — новые вопросы в игре.

| Файл | Что внутри |
|---|---|
| `shutka.json` | 133 обычные затравки, 72 — 18+, 70 — «Жесть», финалы «три вещи…» и запасные ответы на каждый уровень |
| `sanatoriy.json` | 110 вопросов, 25 категорий для побега, задания для процедур |
| `sobes.json` | вопросы для разогрева, три раунда собеседования, слова-связки, должности для победителя, реплики мультвставок; отдельный набор 18+ |
| `lainer.json` | 10 категорий тем, 65 заготовок (из них 25 полётных), 35 — 18+, 24 — «Жесть», финалы «Турбулентность», коронные фразы |
| `baraban.json` | вопросы пяти типов (выбери верные, угадай число, назови больше, пары, «кто из нас») на трёх уровнях и запасные пророчества |
| `gora.json` | 36 опросов по 8 вариантов и 12 опросов 18+ |

Правило для своих текстов — в разделе «Красные линии» ресерча: без политики, войны, религии и насмешек над реальными людьми.

Свои звуки, музыку и фоны можно просто положить в `public/assets/` — игра подхватит их вместо синтеза. Что именно стоит сгенерировать и как назвать файлы — в [docs/ASSETS.md](docs/ASSETS.md).

## В интернет

Компьютер не нужен, если играете с людьми из других городов. Кнопка «Deploy to Render» вверху подхватит `render.yaml`, каждый пуш в `main` деплоится сам. На бесплатном тарифе сервис засыпает после 15 минут тишины — откройте экран заранее. Есть и `fly.toml` для Fly.io.

## Настройки

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | 7700 | порт |
| `ANTHROPIC_API_KEY` | — | включает ИИ |
| `BALAGAN_MODEL` | `claude-opus-5-5` | модель |
| `BALAGAN_TEST` | — | `1` — песочница, боты, короткие таймеры |
| `BALAGAN_ROUNDS` | 3 | раундов в «Шутке на двоих» |
| `BALAGAN_BAR_GOAL` | 20000 | порог победного оборота в «Барабане» |
| `BALAGAN_MAX_ROOMS` | 200 | предел комнат на сервере |

Таймеры каждой фазы тоже настраиваются — имена переменных рядом с `secs(...)` в начале файла игры.

## Как устроено

```
server.mjs                HTTP, WebSocket, QR, общие действия: выбор игры, старт, боты
src/rooms.mjs             комнаты, игроки, переподключение, таймер фазы, голос, планировщик ботов
src/games/<игра>.mjs      правила одной игры
src/ai.mjs                Claude: запросы со структурированным ответом и красными линиями
public/shared/            оболочки экрана и телефона, музыка, звуки, голос, эффекты, темы
public/games/<игра>/      экран, телефон и стиль одной игры
data/                     контент
docs/RESEARCH.md          ресерч: механики, тренды, юмор, ограничения
```

Игра — модуль с `init / start / onAction / viewTV / viewPlayer`, плюс `botMoves` для ботов. Боты ходят теми же действиями, что и люди, поэтому каждая новая игра сразу проверяется в песочнице. Музыка процедурная: секвенсор на Web Audio со своим стилем у каждой игры, без аудиофайлов и лицензий.
