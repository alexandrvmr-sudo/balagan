# 🎪 Балаган

Вечериночные игры как в Jackbox, только по-русски и со своими правилами: **экран на телевизоре, телефоны вместо геймпадов, ведущий не нужен**. Открыл страницу, навёл камеру на QR — играешь.

Первая игра — **«Шутка на двоих»**: каждому прилетает затравка, двое пишут ответы на одну и ту же, остальные голосуют за смешной.

## Быстрый старт

```bash
npm install && npm start
```

| Что | Где открыть |
|---|---|
| Экран | `http://localhost:7700/` — вывести на телевизор |
| Телефоны | QR с экрана, или адрес `http://<IP-ноутбука>:7700/join` и код комнаты |

Экран печатает код из четырёх букв и QR. Телефоны в той же Wi-Fi заходят по нему без установки чего-либо. `F` на экране — полный экран, клик по экрану — включить звук (требование браузеров).

## Задания от ИИ

Без ключа игра идёт на встроенном паке из 48 затравок. С ключом — хост вписывает тему вечера («днюха Макса, все с работы»), и задания сочиняются под конкретную компанию, а ведущий комментирует каждый раунд.

```bash
cp .env.example .env     # вписать ANTHROPIC_API_KEY
npm start
```

Ключ читается при старте, перезапуск не нужен — `.env` подхватывается сам.

## Как играют

1. Все заходят, первый вошедший получает ★ — он хост.
2. Хост жмёт «Начать». Нужно от 3 до 10 игроков, остальные попадают в зал и голосуют наравне со всеми.
3. **Раунд 1** — каждому две затравки, по 1000 очков. **Раунд 2** — то же, но по 2000.
4. **Финал** — одна затравка на всех, пишут все, голосуют все (кроме как за себя), 3000 очков делятся по голосам.
5. Собрать все голоса в паре — это «ШУТКА!», +25% сверху.

Телефон можно заблокировать и вернуться — игрок переподключится в ту же игру по сохранённому токену.

## Выложить в интернет

WebSocket нужен обязательно — подойдёт любой хостинг, который его не режет.

**Fly.io** (конфиг уже в `fly.toml`, машина засыпает между вечеринками):

```bash
fly launch --copy-config --no-deploy
```

```bash
fly secrets set ANTHROPIC_API_KEY=sk-ant-...
```

```bash
fly deploy
```

**Railway / Render**: подключить репозиторий, они сами увидят `Dockerfile`. Задать переменную `ANTHROPIC_API_KEY`, порт берётся из `PORT`.

Публичный адрес для QR определяется из заголовков запроса — настраивать ничего не нужно. `PUBLIC_URL` понадобится только при нестандартном прокси.

## Настройки

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | 7700 | порт сервера |
| `ANTHROPIC_API_KEY` | — | включает ИИ-задания и реплики ведущего |
| `BALAGAN_MODEL` | `claude-opus-5-5` | модель для генерации |
| `BALAGAN_ROUNDS` | 3 | число раундов, последний всегда финал |
| `BALAGAN_WRITE` | 80 | секунд на написание |
| `BALAGAN_VOTE` | 20 | секунд на голосование |
| `BALAGAN_MAX_ROOMS` | 200 | предел одновременных комнат |

## Свои задания

Всё лежит в [`data/shutka.json`](data/shutka.json): `prompts` — обычные затравки, `final` — финальные. Пропуск обозначается `___`. Хорошая затравка короткая (4–12 слов) и допускает десятки разных ответов.

## Что внутри

```
server.mjs            HTTP + WebSocket + раздача статики + QR
src/rooms.mjs         комнаты, коды, игроки, переподключение, таймеры фаз
src/games/shutka.mjs  правила «Шутки на двоих»
src/ai.mjs            генерация затравок и реплик ведущего
public/tv.html        экран
public/join.html      контроллер в телефоне
```

Движок не знает правил: игра — это модуль с `init / onAction / onTimeout / viewTV / viewPlayer`. Новая игра добавляется файлом в `src/games/` и строкой в `GAMES` внутри `server.mjs`.

**Что просится следующим:** «Врун» (выдумать правдоподобную ложь), «Шедевр» (рисовать пальцем и угадывать), редактор паков, сохранение результатов между вечерами.

### Несколько игроков на одном устройстве

Для отладки: `/j/КОД?new=1` — такая вкладка хранит свой токен отдельно, можно открыть хоть пять игроков в одном браузере.
